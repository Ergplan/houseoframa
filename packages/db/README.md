# packages/db

Drizzle schema (`src/schema.ts`), migrations (`migrations/`, generated by `pnpm db:generate`), the migrator and the seed.

- `pnpm db:migrate` applies migrations to `DATABASE_URL`.
- `pnpm db:seed` creates the local member (`RAMA_MEMBER_NAME`) and the site `self`. Idempotent.
- `model_calls` and `audit_log` are append-only: a trigger in the migration refuses UPDATE and DELETE.
