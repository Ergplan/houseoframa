# House of Rama · Pod Edition — product construct (24 Oct 2026)

The full construct with diagrams is the member's document "House of Rama · Pod Edition". This file is its working summary for the builder; where it and older wording in this repository differ, this file wins.

## The promise
A customer walks in with an idea and no code. They build their app themselves, using House of Rama, with a trainer (a developer with three or more years of full-stack experience) beside them. House of Rama shows their product as a transparent isometric lakefront in their own words; code is three clicks away. Each screen is the glass front of a building. Their spoken yes is the first signature; a stranger audits before the keys. They leave knowing it will not break when they touch it, and keep improving it from their own laptop through the same ceremony. House of Rama ships the product. It is not a retail product yet.

## Version 1 (this build)
Used by Aayuda on a laptop to build its first product, ergPLAN, inside House of Rama. English only. Laptop webcam for the board. Wallet and customer-owned GitHub are deferred; keys and the GitHub account live in the Settings screen; no passwords. Floor edition features (bookings, pod lights, campus) exist from Stage 6 but are not the daily path until the floor opens.

## The track (the product)
Screen → Figure → Formula (file:line, parser-read) → Inputs (re-executed values) → Data (table.column) → Build (lift, builder, time) → Signature. Each step is a question the voice can answer, read from capture, trail, schema, git and the signoff record only. Missing step: the voice says "untraced" and names it.

## The three zoom levels
Street (buildings named for what they do, roads, the ground = tables, the lake = the edge, facades = real screens, a flag per building) → Building (floors: shows, decides, remembers, talks to; figures with trails) → Brick (files, cables, lifts, cranes; code on request).

## Voice
GPT Live, a mouth not a mind (Invariant 9): takes inputs, asks, suggests, reads back; writes nothing. The builder hands it every product sentence. Commands: yes, no, scrap everything, show me, open, show me the code, go back, what if.

## The session
1 Arrive · 2 Ideate (board + talk → map + draft cards) · 3 Agree (design explained aloud, including what it will not do; "Yes, build it" = signature one) · 4 Build (between shifts; lakefront rises) · 5 Walk and sign (voice calls each screen; audit; keys). "Scrap" starts a named new draft; the old one is kept, withdrawn.
