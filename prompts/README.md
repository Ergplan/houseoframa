Versioned prompt files, `<name>.v<N>.md`, loaded by packages/model. A prompt is never edited in place; a change is a new version. In use: glossary.v1, purpose.v1, discovery.v1, reviewer.v1, audit.v1, build.v3 (a product's own database, Stage 11; build.v2 built the Stage 9 sample, build.v1 the first runs of the Stage 9 build loop), voice.v1 (the voice's instructions: a mouth, not a mind), narrate.v2 (the design explained aloud, from the decided cards; v1 ended each building with a question the room asks once itself), board.v1 (a frame of the board read into boxes, arrows and labels), clip.v1 (the speaking style of the recorded rehearsal's audio), idea.v1 (the drafter in the idea room, Stage 12: welcoming, it draws the idea out, reads the room's files, searches the web when asked, and proposes cards that only a person's yes decides).
