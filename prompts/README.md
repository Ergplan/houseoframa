Versioned prompt files, `<name>.v<N>.md`, loaded by packages/model. A prompt is never edited in place; a change is a new version. In use: glossary.v1, purpose.v1, discovery.v1, reviewer.v1, audit.v1, build.v2 (build.v1 was used by the first runs of the Stage 9 build loop), voice.v1 (the voice's instructions: a mouth, not a mind), narrate.v1 (the design explained aloud, from the decided cards), board.v1 (a frame of the board read into boxes, arrows and labels), clip.v1 (the speaking style of the recorded rehearsal's audio).
