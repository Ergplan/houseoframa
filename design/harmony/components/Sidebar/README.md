# Sidebar

The desktop navigation rail: the ergOS wordmark and role chip, grouped links with 19px icons, the Dashboard group expanded with a tree line, and the organisation at the foot.

- Current top-level item: `aria-current="page"` on `eg-nav__item` (accent-soft fill, accent icon). Current sub-item: a glowing Harmony dot and accent text.
- Group labels (`eg-overline eg-nav__group`) are optional and short: Monitor, Operate.
- Width 264px. On phones replace it with the TabDock.

The wordmark is set in type ("erg" in ink, "OS" in accent) because no logo file was provided.
